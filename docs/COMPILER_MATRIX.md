# Real compiler compatibility checks

Enable the optional compiler matrix when configuring Beryl:

```sh
cmake -S . -B build-matrix -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_C_FLAGS=-Werror -DBERYL_COMPILER_MATRIX=ON \
  -DBERYL_GCOBOL_EXECUTABLE=/usr/bin/gcobol-15
cmake --build build-matrix --parallel
ctest --test-dir build-matrix --output-on-failure
```

With GnuCOBOL available, this adds IBM and Micro Focus dialect profiles and
strict COBOL 85/2002/2014 profiles. Each vendor profile and GCC COBOL checks:

- Fixed SEQUENTIAL file bytes, golden results, archived replay and detection of
  a deliberately incorrect boundary result.
- Three independent 25-byte records covering ASCII signed DISPLAY, scaled
  decimals and signed/unsigned odd/even packed decimal storage.
- A seeded corpus of 100 generated records, checked by COBOL NUMERIC predicates
  and echoed without any byte changes.
- A generated BY REFERENCE driver, including transformations, return status and
  extra-record rejection.

Strict standards profiles check golden output, replay and boundary regression
using the portable accounts fixtures. The other fixtures use vendor extensions
such as RETURN-CODE and COMP-3; they are not evidence of strict standard support.
IBM and Micro Focus dialect modes remain GnuCOBOL implementations, not validation
on those vendors' products.

`BERYL_GCOBOL_FLAGS` accepts extra compiler options for a nonstandard toolchain
layout. `BERYL_GNUCOBOL31_EXECUTABLE` and `BERYL_OPENCOBOL_EXECUTABLE` select
additional installed compilers. These optional paths never trigger downloads or
license activation. The compiler must have its matching headers, configuration
and runtime libraries available; do not mix different versions' libcob libraries.

Coverage and COPY preprocessing remain separate GnuCOBOL-specific adapters. The
matrix does not imply that those adapters support every compiler.

## Verified checkpoint: 2026-10-29

On x86-64 Ubuntu under WSL, the C17 Debug build with GCC 15.2 and `-Werror`
passed **32/32 CTest suites**, with no skips (28.48 seconds). This includes the
17 existing suites and 15 additional matrix suites: GCC COBOL 15.2 (four),
GnuCOBOL 3.2 IBM and MF modes (four each), and strict COBOL 85/2002/2014 modes
(one each). This result covers the fixtures and configurations above, not the
full language or arbitrary compiler settings.

GCC COBOL came from Ubuntu's `gcobol-15`, `gcobol-15-x86-64-linux-gnu`,
`libgcobol-15-dev` and `libgcobol1` packages, version 15.2.0-16ubuntu1. An
isolated extraction needed `-B/usr/lib/gcc/x86_64-linux-gnu/15/` and its runtime
directory on `LD_LIBRARY_PATH`/`LIBRARY_PATH`. Normal package installations
should not need this extraction-specific setup.

Other compiler builds and proprietary trial access are still being evaluated;
they are not included in this passed count.
